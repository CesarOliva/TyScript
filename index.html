Un laboratorio para aprender compiladores

¿Qué ocurre dentro de un compilador?

TyScript es un proyecto educativo para entender cómo se crea un lenguaje de programación y cómo un compilador transforma lo que escribes, paso a paso.

Explorar el playground ↓

Un lenguaje pequeño, un compilador completo

TyScript tiene tipos como int, float, bool y string, además de arreglos, pilas y colas. Permite declarar variables, usar condiciones y ciclos, y escribir instrucciones como print y read.

Su compilador analiza el programa, comprueba que las operaciones tengan sentido, optimiza una representación intermedia y genera JavaScript. En el playground puedes editar ejemplos, ejecutarlos y seguir las fases léxica, sintáctica y semántica.

program Hola {
  string nombre = "Ada";
  print("Hola " + nombre);
}

Del código fuente a JavaScript

  1. 1. LéxicoConvierte el texto en tokens: nombres, palabras clave y símbolos.
  2. 2. SintaxisComprueba la estructura y construye el árbol del programa.
  3. 3. SemánticaVerifica tipos, declaraciones y ámbitos de las variables.
  4. 4. Código intermedioExpresa las operaciones como instrucciones de tres direcciones.
  5. 5. OptimizaciónAplica mejoras que conservan el resultado del programa.
  6. 6. JavaScriptGenera el código final para ejecutar el programa.

Escribe y ejecuta programas en TyScript, consulta los ejemplos y observa las primeras fases en modo paso a paso. Todo ocurre en tu navegador.
